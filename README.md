# 💬 Super Server Discord Bot

Офіційний Discord-бот для міжвимірного хабу спільноти Майнкрафт-сервера **«Super Server: Aeterna Edition»**. Відповідає за модерацію, синхронізацію та автоматизацію серверних процесів.

---

## 🚀 Основний функціонал

* 👥 **Керування спільнотою:** автоматична видача ролей, модерація текстових і голосових каналів.
* 📊 **Статус та 24/7 Онлайн:** підтримка безперервної роботи сервера через `keep_alive.py`.
* 🔒 **Захист даних:** безпечне збереження Discord API токенів через змінні оточення (Environment Variables).

---

## 🛠️ Стек технологій

* **Python 3** — основна мова розробки.
* **Render / Uptimerobot** — веб-сервер для підтримки 24/7 статусу на хостингу.

---
